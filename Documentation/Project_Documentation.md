# Project Documentation

## Overview
This project presents a Power BI cryptocurrency analytics dashboard based on the supplied CryptoData.xlsx dataset.

## Data Flow
CryptoData.xlsx -> Power BI -> data preparation/modeling -> measures/visuals -> interactive dashboard.

## Main Dashboard
The supplied dashboard includes cryptocurrency and year selectors plus KPI cards for Volume, Market Cap, High, Average and Low, and a Market Cap by Date trend chart.

## Price Trends Analysis
The second page includes KPI cards for Volume and Market Cap and line charts for High vs Low and Open vs Close by date.

Open the PBIX file using Power BI Desktop. When prompted to locate source data, use Data/CryptoData.xlsx.

## Interpretation Note
Dashboard figures and screenshots are supplied project outputs and should not be treated as live market values.
